# 리틀 룬 가디언즈 · Little Rune Guardians

작은 수호자가 룬의 숲을 지키는 한국어 2.5D 생존 액션 게임입니다. 이동과 회피에 집중하면 무기는 가까운 적을 자동으로 공격합니다. 로그인과 게임 백엔드 없이 데스크톱 브라우저에서 실행되며, 화면은 Canvas로 직접 그리고 효과음은 Web Audio로 합성합니다.

## 실행

Node.js 22.12 이상을 권장합니다. 검증 환경은 Node.js 24.14.0입니다.

```sh
npm ci
npm run dev
```

개발 서버는 기본적으로 `http://127.0.0.1:4173/`에서 열립니다. 포트가 이미 사용 중이면 터미널에 표시되는 주소를 사용하세요.

프로덕션 빌드와 미리보기는 다음 순서로 실행합니다.

```sh
npm run build
npm run preview -- --strictPort
```

이번 실행에서 확인한 프로덕션 미리보기 주소는 `http://127.0.0.1:4174/`, 대시보드는 `http://127.0.0.1:4310/`입니다. 위 명령은 포트가 점유되면 종료하므로 다른 서버를 임의로 끄지 말고 `--port 4180` 등으로 다른 포트를 지정해 터미널에 표시된 실제 주소를 여세요. 대시보드가 다른 포트를 선택했다면 `.agent-monitor/data/runtime.json`의 `url`이 기준입니다. 배포 파일은 `dist/`에 생성됩니다. 별도 외부 서비스 없이 정적 파일로 제공할 수 있습니다.

```sh
npm run typecheck
npm test
```

## 게임 규칙

- **일반 임무:** 10분 생존. 버섯 왕은 8:00, 돌 골렘은 9:00에 등장합니다.
- **빠른 시연:** 같은 전투와 성장 규칙을 3분으로 압축합니다. 버섯 왕은 2:00, 돌 골렘은 2:30에 등장합니다. 자세한 진행은 [DEMO.md](DEMO.md)를 참고하세요.
- **시드 도전:** `0`부터 `4294967295`까지의 숫자를 입력해 같은 시드와 캐릭터로 같은 출발 조건에 도전합니다. 일반 임무와 같은 10분 규칙이며, 도전 결과는 저장된 일반 최고 기록을 덮어쓰지 않습니다.

세 모드 모두 제한시간까지 살아남고 두 보스를 처치해야 승리합니다. 시간이 0:00이 되었을 때 보스가 남아 있으면 전투가 끝나지 않고, 남은 보스를 모두 처치할 때까지 이어집니다. 체력이 0이 되면 즉시 패배합니다. 레벨업 화면에서는 전투 시간이 멈추며 세 카드 중 하나를 고릅니다.

## 조작

| 입력 | 이동 | 대시 | 일시정지 | 메뉴·성장 선택 |
|---|---|---|---|---|
| 키보드·마우스 | `WASD` 또는 방향키 | `Space` 또는 `Shift` | `Esc` 또는 `P` | 클릭 또는 성장 카드 `1`·`2`·`3` |
| 표준 매핑 게임패드 | 왼쪽 스틱 또는 D-pad | `A`, `LT`, `RT` 중 하나 | `Start` | 스틱/D-pad로 이동, `A`로 확인, 가능한 화면에서 `B`로 뒤로 |
| 터치 | 전투 중 왼쪽 가상 조이스틱 | 오른쪽 `대시` | 오른쪽 `Ⅱ` | 시작 화면과 성장 카드를 직접 터치 |

공격 버튼은 없습니다. 보유 무기가 자동으로 공격하므로 적의 공격 예고를 보고 움직이거나 대시하세요. 창이 포커스를 잃거나 페이지가 숨겨지면 입력을 해제하고 진행 중인 게임을 일시정지합니다.

키보드와 마우스 경로는 브라우저 검증 대상입니다. 표준 매핑 게임패드와 coarse-pointer 터치 입력은 구현 및 자동 검사를 거쳤지만, 물리 게임패드와 실제 터치 기기에서의 최종 실측 여부는 [VALIDATION.md](VALIDATION.md)에서 확인하세요.

### 대시 충전

| 수호자 | 시작 충전 | 한 칸 충전 시간 | 레벨 8 이후 최대 충전 |
|---|---:|---:|---:|
| 로완 · 기사 | 2회 | 5초 | 3회 |
| 루미 · 마법사 | 1회 | 4초 | 2회 |
| 페른 · 궁수 | 3회 | 6초 | 4회 |

보유 횟수가 남아 있으면 대시를 연속으로 사용할 수 있지만, 각 사용 사이에는 0.85초의 간격이 있습니다. 빈 칸은 한 칸씩 순서대로 충전되며, 충전 도중 다시 대시해도 진행 중인 충전 시간은 초기화되지 않습니다. 레벨 8에 도달하면 최대치가 한 번만 1칸 늘어나고 새 칸은 빈 상태에서 충전을 시작합니다. `바람 장화`는 한 칸의 충전 시간을 단계마다 8% 줄이며, 최소 충전 시간은 3초입니다.

전투 HUD는 현재 횟수와 최대 횟수, 충전된 칸, 다음 한 칸의 진행률과 연속 사용 대기시간을 표시합니다. 터치 화면의 대시 버튼도 남은 횟수와 충전 진행률을 함께 보여줍니다.

## 콘텐츠

### 수호자 3명

| 수호자 | 시작 무기 | 특징 |
|---|---|---|
| 로완 · 작은 새벽 기사 | 새벽의 검 | 최대 체력 120, 넓은 근접 검격, 대시 2회 |
| 루미 · 별빛 견습 마법사 | 수호 정령 | 모든 공격 피해 12% 증가, 대시 1회 |
| 페른 · 숲길의 작은 궁수 | 숲지기 활 | 이동 속도 190, 대시 3회 |

### 무기 6종

| 무기 | 동작 |
|---|---|
| 새벽의 검 | 가까운 적을 넓은 부채꼴로 베기 |
| 숲지기 활 | 가장 가까운 적에게 빠른 화살 발사 |
| 수호 정령 | 플레이어 주변을 공전하며 접촉 공격 |
| 천둥 룬 | 여러 적 사이를 잇는 연쇄 번개 |
| 서리 마법서 | 주변에 피해와 둔화를 주는 얼음 고리 |
| 불씨 지팡이 | 적에게 날아가 착탄 지점에서 폭발하는 화염구 |

일반 적은 **슬라임, 버섯, 고블린, 해골, 박쥐, 딱정벌레** 6종입니다. 버섯은 조준 뒤 화면을 날아오는 포자를 발사하고, 해골은 부채꼴 예고 뒤 뼈 투사체 3개를 동시에 던집니다. 이 공격은 실제 비행 경로에서 플레이어와 충돌할 때 피해를 줍니다.

보스는 왕실 포자와 고리 충격파를 사용하는 **버섯 왕**, 균열선과 충격 고리를 사용하는 **돌 골렘** 2종입니다. 버섯 왕의 왕실 포자는 표시된 목표로 실제 비행한 뒤 충돌 지점에서 폭발합니다. 고리 충격파, 골렘의 균열과 충격 고리, 일반 적의 돌진처럼 바닥에 범위가 표시되는 근접·장판형 공격도 유지됩니다. 투사체는 옆으로 피하고, 바닥 공격은 예고된 범위 밖이나 안전 구역으로 이동하세요.

성장 카드는 16종입니다: 새벽의 검, 숲지기 활, 수호 정령, 천둥 룬, 서리 마법서, 불씨 지팡이, 용기의 문장, 재빠른 손, 생명의 새싹, 바람 장화, 별빛 주머니, 바람 관통, 분열 씨앗, 연쇄 전격, 숲의 축복, 수호의 망토.

두 가지 룬 조합은 필요한 카드를 모두 얻으면 자동으로 활성화됩니다.

- **숲의 화살비:** 숲지기 활 + 바람 관통 + 분열 씨앗. 관통 화살이 적을 뚫고 작은 화살로 갈라집니다.
- **천둥 수호대:** 수호 정령 + 연쇄 전격. 정령이 명중한 적에서 주변 적으로 번개가 이어집니다.

시작 화면의 `룬 조합 도감`에서 수호자, 무기, 조합 조건을 다시 볼 수 있습니다.

## 저장과 설정

결과 화면에 생존 시간, 처치 수, 점수와 최고 점수가 표시됩니다. 일반 임무와 빠른 시연의 최고 점수·최장 생존 시간·승리 횟수는 서로 분리합니다. 이 기록과 아래 설정은 브라우저 `localStorage`의 `little-rune-guardians.v1`에 저장됩니다.

- **소리 켜짐/꺼짐:** 합성 효과음을 음소거합니다.
- **화면 흔들림 켬/줄임:** 피격과 강한 공격의 카메라 흔들림을 줄입니다.

설정은 `Esc` 또는 `P`로 연 일시정지 화면에서 바꿉니다. 저장소를 지우면 기록과 설정도 초기화됩니다. 저장소를 사용할 수 없거나 값이 손상된 경우 게임은 기본값으로 계속 실행합니다.

## 검증과 에셋

최종 빌드, 테스트, 실제 플레이와 입력 장치 결과는 [VALIDATION.md](VALIDATION.md)에 정리했습니다. 성능과 일반 임무 10분 재검증의 최종 판정도 해당 문서를 기준으로 확인하세요. 원시 결과와 화면 캡처는 [`evidence/`](evidence/)에 보존합니다.
