# 리틀 룬 가디언즈 · Little Rune Guardians

작은 기사가 룬의 숲을 지키는 한국어 2.5D 생존 액션 게임입니다. 로그인이나 게임 백엔드 없이 데스크톱 브라우저에서 플레이합니다. 그래픽은 직접 그린 Canvas 디오라마, 효과음은 Web Audio 합성입니다.

## 실행

Node.js 22.12 이상 권장(개발 환경 24.14.0).

```sh
npm ci
npm run dev
```

게임: http://127.0.0.1:4173/ (포트 사용 중이면 실행 출력의 주소 확인).

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

프로덕션: http://127.0.0.1:4174/ . 배포 파일은 `dist/`입니다. 별도 외부 서비스 없이 정적 서버로 제공할 수 있습니다.

## 조작

- WASD / 방향키: 이동
- Space / Shift: 대시 (대기시간 이후 재사용)
- 자동 공격: 가까운 적을 자동으로 공격
- ESC / P: 일시정지·재개
- 레벨업 때 카드 클릭 / 1, 2, 3: 룬 선택

10분 동안 생존하고 버섯 왕을 물리치면 승리합니다. 시간이 끝났는데 보스가 살아 있으면 마지막 보스전이 이어집니다. 체력이 0이면 패배합니다. 빠른 시연은 같은 전투 기능을 사용하는 3분 모드입니다. 일시정지 화면에서 음소거와 화면 흔들림 감소를 바꿀 수 있고, 최고 기록과 설정은 브라우저에 저장됩니다.

## 진행 관찰

```sh
python3 .agent-monitor/collector.py
```

기본 http://127.0.0.1:4310/ . 실제 주소와 PID는 `.agent-monitor/data/runtime.json`에 기록됩니다. 운영·중지·최종 저장본 재열람은 `.agent-monitor/README.md`를 참고하세요. 현재 작업과 메인이 생성한 하위 에이전트만 관찰하며, 원본 세션 로그나 계정 토큰·비용은 수집하지 않습니다.

## 검증과 라이선스

현재 검증 상태는 `STATUS.md`, 최종 결과는 `VALIDATION.md`에 기록합니다. 스크린샷과 원시 측정 결과는 `evidence/`에 보존합니다. 자동 실제 플레이는 일반 UI 클릭과 키보드만 사용하며 관측 API로 게임을 변경하지 않습니다.
