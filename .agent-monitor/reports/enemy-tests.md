## 비유한 속도 결함 재현

방어적 안정성 결함 하나를 별도 격리 프로세스에서 재현했다. 정상 게임 스폰과 입력으로는 도달하지 않으며, 테스트 fixture처럼 `getState()`가 반환한 내부 적 객체의 `speed`를 `Infinity`로 손상시켜야 한다.

- 심각도 제안: **P1 방어적 안정성**. P0 정상 플레이 차단으로 판정하지 않았다.
- 재현: 시작한 게임에서 일반 적 하나의 `speed = Infinity`로 설정하고 `step(0.01, NO_INPUT)` 호출. 프로세스에 1초 제한을 걸었다.
- 기대: 비유한 운동 값을 무시하거나 유한 범위로 정규화하고 `step`이 반환한다.
- 실제: 제한 시간 종료 코드 `124`; `completed` 출력 없음.
- 원인: `moveBody`의 `Math.ceil(Math.hypot(dx, dy) / 10)`이 `Infinity`가 되어 `for (n < slices)`가 끝나지 않는다. 첫 반복의 `Infinity / Infinity`는 좌표를 NaN으로 만들지만 반복 횟수는 계속 Infinity다.
- 정상 경로 분석: `step`은 비유한/비양수 dt를 거부하고 50ms로 제한하며, 플레이어 입력은 유한성 확인과 범위 제한을 거친다. 일반 적의 생성 위치·기본 속도·고블린 돌진 속도도 모두 유한하다. 따라서 현재 게임 규칙만으로 이 결함에 들어가는 경로는 확인하지 못했다.
- 권고: `moveBody` 진입에서 `dx`, `dy`의 유한성을 검사하고, 이동 조각 수에 상한을 두며, 갱신 대상 body 좌표·속도가 비유한 경우 안전하게 복구하거나 해당 개체를 건너뛴다. `getState()`의 실제 객체가 외부에 그대로 노출되는 계약도 별도로 검토할 가치가 있다.

소스는 요청 범위에 따라 수정하지 않았다. 이 결함은 기대/실제/재현 결과와 함께 메인 담당자에게 즉시 전달했다.
