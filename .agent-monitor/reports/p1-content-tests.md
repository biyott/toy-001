# P1-CONTENT-TEST — P1 콘텐츠 계약 독립 검사

- 수정 범위: `tests/p1-content.test.ts`와 이 보고서만. 게임 코드 수정 없음.
- 실행 범위: `npx tsx --test tests/p1-content.test.ts`만 실행. 전체 테스트·전체 빌드·브라우저 검증은 실행하지 않음.
- 중복 회피: 보스 패턴과 무기별 충돌·공격 규칙은 다른 담당 검사 범위이므로 다루지 않았다. 이 검사는 콘텐츠 수량·선택 반영·등장 일정·승리 조건에 한정한다.
- fixture 경계: 공개 상태 fixture로 XP, 성장 카드, 보스 체력과 시간을 경계 직전에 배치했다. 엔진의 `step`/`dispatch`가 실제 상태 전이를 수행하지만 정상 브라우저 플레이 증거를 대체하지 않는다.

## 결함

검사 범위에서 결함을 발견하지 못했다. P1 보스 모듈이 공유 작업공간에 반영된 뒤 최종 전용 검사를 실행했으며 9개 모두 통과했다.

실제 플레이에서 세 캐릭터 선택 UI, 성장 카드 노출, 두 보스 조우와 승리를 확인하는 일은 별도 브라우저 검증이 필요하다.
