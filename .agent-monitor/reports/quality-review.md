## 제한된 개선 권고 — 최대 3개

### QV-01 / P2 — 잔디 청크 이음새 제거

- 재현: `prototype-play.png`를 원래 크기로 열고 중앙 기사 아래를 가로지르는 y≈330, 중앙 x≈640의 지면만 본다. 이후 메인 브라우저에서 천천히 좌우·상하 이동하여 해당 선이 지면과 함께 이동하는지 확인한다.
- 관찰: 큰 연녹색/황록색 잔디 타원이 수평·수직 선에 잘려 서로 다른 직사각형 판처럼 보인다. 실제 캡처에서 확인한 문제다. `Ground.create`가 큰 타원을 각 512px 청크 안에서 독립 생성하는 코드가 원인 추정과 일치한다.
- 기대: 한 덩어리의 자연스러운 풀밭으로 읽혀야 한다. 이동 중 격자 선이 시선을 끌지 않아야 한다.
- 권고: 큰 패치를 세계 좌표로 결정하고 경계를 걸친 패치를 이웃 청크에도 동일하게 그린다. 더 작은 수정으로는 큰 패치의 가장자리 가중치를 줄인다. 기존 도로·소품·랜드마크는 유지한다.
- 검증: 같은 720p 위치와 청크 경계 이동 캡처에서 타원 절단선이 없어졌는지 비교. 게임 규칙 변경 불필요.

### QV-02 / P2 — 전투 배우와 지면의 대비를 제한적으로 보강

- 재현: `prototype-play.png`에서 (약 650,330)의 기사, 좌상단·우상단 슬라임과 지면을 비교한다. 추가로 적·경험치·공전 정령·위험 예고가 동시에 있는 정상 전투 화면을 확인한다.
- 관찰: 현재 작은 기사의 표정과 실루엣은 읽히지만, 밝은 금속/세이지 바닥의 명도차가 작고 발밑 금색 링은 돌길 위에서 약하다. 슬라임도 초록 지면과 색조가 가깝다. **혼전에서 위치를 실제로 잃는지는 아직 관측하지 않았다.**
- 기대: 복잡한 전투에서도 플레이어와 적 종류, 피해를 주는 위험을 즉시 찾을 수 있어야 한다.
- 권고: 밀집 캡처에서도 같은 문제가 확인되면 플레이어 외곽선과 발밑 링을 한 단계 진하게 하고, 적 외곽선 또는 밑그림자만 소폭 강화한다. 팔레트 전체를 강한 원색으로 바꾸거나 장식 수를 늘릴 필요는 없다.
- 검증: 같은 전투 밀도의 수정 전후 화면에서 중앙 캐릭터, 슬라임/버섯/고블린, 위험 예고 형태가 분리되는지 비교. 위험 예고는 색뿐 아니라 형태·움직임도 확인.

### QV-03 / P2 — 시작·시간 안내에 보스 처치 조건을 명시

- 재현: 처음 접속한 사용자처럼 `prototype-title.png`의 설명과 `prototype-play.png`의 시간 아래 안내만 읽는다. 현 소스의 종료 조건과 비교한다.
- 관찰: 시작은 “마을을 지키세요”, HUD는 “밤이 끝날 때까지 버티세요”라고 설명한다. 그러나 현재 종료 규칙은 `elapsed >= duration && bossDefeated`이며 시간만 채워서는 승리하지 않는다. 이 불일치는 캡처 문구와 코드에서 확인했다.
- 기대: 시작 후 30초 안에 이동/대시/자동공격뿐 아니라 승리 목표도 이해할 수 있어야 한다.
- 권고: 기존 안내 한 줄을 “10분을 버티고 버섯 왕을 물리치세요”처럼 실제 규칙에 맞게 바꾼다. 3분 시연에서는 3분으로 표시하고, 0:00 이후에는 “마지막 보스를 처치하세요”를 시간 근처에 유지한다. 새 화면·기능 추가는 불필요하다.
- 검증: 720p·1080p에서 줄바꿈/잘림이 없고, 0:00 보스 생존 상태에서 목표가 남는지 확인.

P2는 현 화면에서 즉시 플레이를 막는 중대 결함을 관측하지 않았다는 뜻이다. 미검증인 혼전·가림·종료 경로가 통과했다는 뜻은 아니다. 구현 배정과 우선순위 조정은 메인에게 맡긴다.

## 최종 판단에 필요한 후속 증거

새 기능 요구가 아니라 이미 정해진 P0 검증의 미확인 부분이다.

- 정상 10분 플레이의 시작→성장 선택→두 무기 조합→보스 예고/공격→승리 증거와 패배·재시작 3회 결과.
- 나무/건물 뒤로 이동할 때 투명화·실루엣과 앞뒤 순서, 입력 방향, 이동·공격·피격 반응이 드러나는 캡처 또는 메인의 실제 조작 관측.
- 720p·1080p 성장·보스·결과·일시정지 화면, 후반 혼전 화면. 타이틀에 없는 UI를 현재 두 장으로 통과 처리하지 않는다.
- 잠금된 최종 코드/빌드 식별자, 콘솔 오류 유무, 설정/저장/손상 복구·일시정지 시간 정지 결과.
- 대표 고부하 구간의 환경·개체 수·측정 시간·프레임 시간. 정지 화면만으로 60fps를 주장하지 않는다.

현재 화면만으로 렌더링 엔진을 교체할 근거는 없다. 한 번의 제한된 마감 개선 후 실제 플레이 증거로 재평가하는 것이 타당하다.

### 동결 P0에서 새로 관측한 작은 UI 결함

이는 초기 3권고와 별개로 이번에 처음 받은 성장/결과 화면에서 발견한 기존 P0 문제다. 새 기능 확장 요구가 아니다. 메인에게 전달했으며 소스 수정은 하지 않았다.

- **QV-04 / P2 — 성장 선택 아이콘이 비어 있음.** 재현은 `p0-demo-growth.png`의 세 카드 상단 원을 비교하는 것. 관찰은 활·정령·주머니 모두 글자/기호 없는 보라 원으로 보인다는 점이다. 기대는 카드별 상징이 보이고 텍스트와 함께 빠르게 구별되는 것. 현재 소스는 각 이름 첫 글자를 넣도록 되어 있어 동결 빌드의 폰트/스타일 표시를 점검하거나 간단한 기호로 보완하면 된다. 검증은 다음 성장 캡처에서 세 상징이 보이는지 확인. 텍스트 이름·설명·키 입력은 선명하므로 선택 기능 자체의 실패라고 판정하지 않는다.
- **QV-05 / P2 — 180초 결과가 3:01로 표시됨.** 재현은 `p0-demo-result.png`의 생존 시간과 JSON elapsed를 비교하는 것. 관찰은 180.00000000003539초가 3:01로 표시된다는 점이다. 소스 `formatTime`의 Math.ceil이 부동소수점 잔여분을 올림하는 것과 일치한다. 기대는 경과 생존시간 3:00, 남은 시간은 기존 카운트다운 정책 유지. 검증은 180/600초 경계의 결과 표시를 확인. 게임이 1초 더 길게 진행됐다는 의미로 해석하지 않는다.

### 추가 단위 검사 보고 읽기

다음은 테스트 작성자 보고를 읽은 결과다. 이 리뷰에서 실행하거나 실제 플레이로 재현한 것이 아니다.

- 버섯 왕 13/13, XP·성장6/6, 일반 적7/7, 자원 상한6/6, 조합4/4 통과 보고를 확인했다. 모두 fixture 경계를 명시하며 실제 브라우저를 대체하지 않는다.
- movement 보고는 6개 중5개 통과, 모서리 소품 반발 후 월드 밖 좌표가 남는 fixture 실패1개를 보존한다. `enemy-tests.md`도 외부 fixture가 적 속도를 Infinity로 손상시킬 때 무한 반복되는 방어적 경계를 보고한다. 정상 플레이로 두 조건에 도달했다는 근거는 현재 없다. 메인으로부터 이동 보완 작업 진행 중이라는 보고를 받았으며 **수정·재검증 완료로 처리하지 않는다.**
