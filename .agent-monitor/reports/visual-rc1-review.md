## VR-01 / P2 — 작은 가로 화면에서 점수판이 보스 진행 표시를 덮음

- **재현:** 844×390, 터치 가능한 가로 화면에서 시연을 시작한다. `evidence/rc1-touch-landscape.png`의 우상단을 확인한다.
- **관찰:** 시간 패널은 x≈650,y≈18에서 아래 약118까지 사용한다. `우두머리 0 / 2` 줄은 y≈100~110에 있는데, 처치/점수 패널이 x≈662,y≈106부터 앞에 그려져 이 줄과 시간 패널 하단 테두리를 덮는다. 이는 실제 제공된 캡처에서 확인한 문제다.
- **기대:** 남은 시간·목표 보스 진행·처치/점수가 각각 가려지지 않아야 한다. 보스0/2는 P1의 승리조건 이해에 필요한 정보다.
- **코드 대조:** 읽기만 한 `src/ui/styles.css`의 `max-width:900px` 분기에서 `.run-stats { position:absolute; top:105px; right:20px; }`를 고정한다. 보스 진행 줄이 포함된 시간 패널 높이와 충돌하는 관측에 부합한다.
- **제한된 수정 제안:** 작은 화면에서 점수판을 시간 패널의 실제 하단 아래로 배치하거나, 두 요소를 같은 세로 레이아웃으로 묶는다. 기존 정보를 없애거나 기능을 추가할 필요는 없다.
- **확인 기준:** 같은844×390에서 시간·0/2·처치/점수 텍스트와 테두리가 겹치지 않는 새 캡처. 1280×720·1920×1080의 현재 정상 배치는 유지되어야 한다.
- **상태:** 메인에게 전달. 이 보고서 작성 시 수정 후 새 캡처는 아직 보지 않았다.
