# T-XP — XP·성장 후반 경계 검사

- 역할: reviewer / XP·성장 late-run 경계.
- 수정 범위: `tests/progression.test.ts`와 이 보고서만. 게임 소스 수정 없음.
- 실행 범위: `npx tsx --test tests/progression.test.ts`만 실행. 전체 빌드·전체 테스트·브라우저 검증은 실행하지 않음.
- fixture 경계: 상태 fixture는 XP 수집과 최대 레벨 조건을 짧고 결정적으로 구성하는 단위 검사 전용이다. 정상 브라우저 플레이 증거를 대체하지 않는다.

## 결함

검사 범위에서 게임 소스 결함은 발견하지 못했다. 첫 실행의 잔여 XP 기대값 0은 계산 오류였고, 실제 공식에 맞는 27로 테스트를 바로잡은 뒤 통과했다.

정상 브라우저에서 실제 전투→XP 수집→여러 성장 선택을 수행하는 검증은 별도 P0 플레이 증거가 필요하다. 이 보고서의 fixture 검사는 그 경로의 대체 증거가 아니다.
